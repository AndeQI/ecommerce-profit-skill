# 电商单品定价与促销盈亏测算 Skill（豆包优先候选版）

此仓库为**免费、通用、用户自行提供业务数据**的 Skill 候选版。不会预设店铺数据、商品售价、采购成本、平台费率，亦不要求商家编辑源码。

## 文件用途

- `SKILL.md`：技能入口，定义触发、输入处理、执行、业务计算规则、输出与安全边界。
- `scripts/calculate.py`：纯本地、无第三方依赖的确定性计算模块。
- `tests/test_calculate.py`：本地计算回归测试。
- `examples/纯模拟输入.json`：测试数据，**不作为用户默认数据**。
- `用户输入说明.md`：商家使用参考。

## 发布到 GitHub

新建 GitHub 仓库，将本 ZIP **解压后的全部文件放在仓库根目录**，确保直接访问仓库时就能看见 `SKILL.md`；不要把 ZIP 文件本身作为唯一上传内容，也不要把所有文件多包一层目录。

然后通过用户已经验证可用的豆包工作 GitHub 安装路径导入该仓库。这个包本身并不是 GitHub 仓库链接，**当前没有创建实际仓库，也没有做豆包安装实测**。

## 用户使用

安装后直接输入自然语言，例如：「请按我下面提供的售价、成本和费用测算已知单笔贡献额。缺少关键数据时请先问我，不要自行填数。」用户随后提供自己的商品资料即可。

## 本地核验

```bash
python -m unittest discover -s tests -v
python scripts/calculate.py < examples/纯模拟输入.json
```

计算仅覆盖用户明确列出的费用，不等于最终净利润。实际能否运行脚本取决于豆包所在运行环境的工具权限。未验证时不能声称已经兼容。
