## 安装与使用

本 Skill 面向电商经营者，提供通用的商品成本、单笔盈亏和促销保本测算能力。

### 安装方式

通过豆包工作支持的 GitHub Skill 安装功能，导入本项目仓库。

### 使用方法

安装完成后，直接向豆包提出相关业务问题，并提供自己的经营数据，例如：

- 商品售价
- 商品采购成本
- 物流及包装费用
- 平台扣费
- 促销优惠

Skill 将根据用户提供的数据进行计算，必要时询问缺失的关键信息，并输出相应的分析结果。

### 注意事项

- 不预设任何商家的经营数据。
- 不要求用户修改 Skill 源代码。
- 计算结果取决于用户提供的数据及成本口径。
- 本版本仍处于测试阶段，尚未完成豆包实际运行验证。
